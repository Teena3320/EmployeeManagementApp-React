# Employee Management System (EMS)

A full‑stack **Employee Management System** built using **Spring Boot**, **React**, and **MySQL**.  
The application provides RESTful APIs backed by a modern React UI for managing employees, departments, and office locations.

---

## 🚀 Features

- Employee CRUD operations
- Department and location management
- Employee–Department–Location relationships
- Search and filtering
- RESTful API design
- React-based frontend dashboard
- MySQL database with JPA/Hibernate
- Toast notifications and modal forms

---

## 🧩 Tech Stack

### Backend
- Java 17
- Spring Boot 3.2.x
- Spring Data JPA (Hibernate)
- Spring Security (basic config)
- MySQL
- Maven

### Frontend
- React
- JavaScript (Hooks)
- Fetch API
- Custom CSS styling
